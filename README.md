## 📄 Task Descriptions

### Task 1 — Personal Webpage
A personal page featuring a profile photo, About Me / My Goals / My Skills sections, and a Useful Links block. Uses semantic tags (`header`, `main`, `section`, `aside`, `footer`) and all three CSS selector types (element, class, id).

### Task 2 — Div-based Layout
A classic website layout (header / navbar / sidebar / content / footer) built with only `<div>` elements, using `float` and `clear` — no Flexbox or Grid.

### Task 3 — Tribute Page
A tribute page dedicated to basketball player LeBron James: biography, key career milestones, list of achievements, an image, and a "Learn More" button linking to Wikipedia. Two Google Fonts are used.

### Task 4 — Table & Form
A grades table (using `rowspan`, alternating row colors, and a highlighted row) and a feedback form with text fields, `select`, `radio` buttons, and a `textarea`.
